# Medito onboarding

Interactieve onboarding voor Medito, opgebouwd rond vijf Lottie-animaties uit
After Effects. De interface wisselt binnen één pagina en ondersteunt knoppen,
paginabolletjes, pijltjestoetsen en swipen.

Op het derde scherm kan de ademhalingsanimatie door een klik of tik worden
gepauzeerd en hervat.

## Lokaal starten

Vereist Node.js 22.13 of nieuwer.

```bash
npm install
npm run dev
```

## Controleren

```bash
npm test
```

De originele opdrachtbestanden blijven beschikbaar in `after-effects/`,
`design/` en `assets/`.
